This template defines how the Examination details report shall
look within the Examination details page. The surrounding page
chrome (breadcrumb, page header, action buttons) is out of scope.

CONVENTIONS USED IN THIS DOCUMENT
──────────────────────────────────
  "static text"       — literal string rendered in the UI
  [field name]        — dynamic value (plain weight unless noted)
  [field name bold]   — dynamic value, font-weight: 600
  [field name link]   — dynamic value rendered as a hyperlink
  [yes/no]            — boolean displayed as "Yes" / "No"
  [free text]         — multi-line text block, whitespace preserved
  ← depends on type → — value or visibility depends on exam type
  (conditional)       — tile/section only rendered when applicable

FIELD TYPE REFERENCE
────────────────────
  Date values         — format: MMM D, YYYY (e.g. "Jun 12, 2026")
                        [implementation uses formatPlainDate / calcEDD as-is]
  Gestational age     — format: Xw Yd  (e.g. "28w 3d")
                        twins: T1 Xw Yd / T2 Xw Yd
  Percentile values   — appended with " %-ile" (e.g. "32.4 - 45 %-ile")
  Datetime values     — format: "MMMM D, YYYY, hh:mm a" (e.g. "June 12, 2026, 10:30 AM")
                        [implementation uses formatDateTime as-is]

  Field notes:
  • "GA from Bio" is shown for ALL exam types — prenatal and first trimester alike.
  • For first-trimester exams, GA from Bio is computed from CRL (Robinson 1975).
    The label "GA from Bio" is used consistently; the underlying formula is CRL-based.
  • For prenatal exams, GA from Bio is a composite of BPD, HC, AC, FL measurements.
  • For twin exams, gestational age format is: "T1 Xw Yd / T2 Xw Yd"


============================================================
CLINICAL SECTIONS — 2 PATHS (mutually exclusive)
============================================================

  The clinical section renders one of two layout paths depending
  on the exam type. Within each path, a single fetus uses only
  the left column; twin exams populate both columns. The two-column
  grid is always 50%/50% — the left column does NOT expand to full
  width when the right column is hidden.

  PATH ROUTING:
  ┌──────────────────────────────────────┬───────────┐
  │ Exam Type                            │ Path      │
  ├──────────────────────────────────────┼───────────┤
  │ ultrasound_prenatal                  │ A (1 col) │
  │ ultrasound_prenatal_twins            │ A (2 col) │
  │ ultrasound_first_trimester           │ B (1 col) │
  │ ultrasound_first_trimester_twins     │ B (2 col) │
  └──────────────────────────────────────┴───────────┘
